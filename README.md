# Phone

This is a Visual Studio 2008 VB.NET Windows Mobile solution with two empty CallInfo class libraries. CallInfo2.0 targets the Windows Mobile 5.0 Smartphone SDK on .NET Compact Framework 2.0; CallInfo3.5 targets the Windows Mobile 5.0 Pocket PC SDK on .NET Compact Framework 3.5. Each project is still the generated `Class1` stub with no call-log or telephony code. This is Dave Robinson's working copy from Historical Dev.

**Source last updated:** 2010-02-17  
**Language:** VB.NET  
**Target:** .NET Compact Framework 2.0 (Smartphone) / 3.5 (Pocket PC)  
**Output:** class libraries

## Solution structure

| Project | Language | Type | Purpose |
|---------|----------|------|---------|
| `CallInfo2.0` | VB.NET | Compact Framework library | Empty `Class1` stub for Windows Mobile 5.0 Smartphone (.NET 2.0) |
| `CallInfo3.5` | VB.NET | Compact Framework library | Empty `Class1` stub for Windows Mobile 5.0 Pocket PC (.NET 3.5) |

## How to open

Open `Phone.sln` in Visual Studio 2008 with the Windows Mobile 5.0 Smartphone and Pocket PC SDKs. The projects deploy as Compact Framework class libraries.
